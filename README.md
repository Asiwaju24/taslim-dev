# taslim-dev — Personal Portfolio

> Portfolio website of **Taslim Olaonipekun Olaniyan** — Full-Stack Developer & ML Engineer.

Live at: [https://asiwaju24.github.io/taslim-dev](https://asiwaju24.github.io/taslim-dev) *(after enabling GitHub Pages)*

## Tech
- Pure HTML, CSS, JavaScript — zero dependencies, zero build step
- Google Fonts: Playfair Display · DM Sans · JetBrains Mono
- Palette: Midnight Executive (Navy · Gold · Steel Blue)

## Sections
- Hero — name, title, code snippet, stats
- About — bio, focus areas
- Stack — skills by category
- Projects — 6 featured projects
- Contact — email, phone, GitHub, LinkedIn

## Deploy on GitHub Pages
1. Go to **Settings → Pages**
2. Source: `main` branch, `/ (root)`
3. Save — live in ~60 seconds

## Local preview
```bash
# No build needed — just open in browser
open index.html
```
